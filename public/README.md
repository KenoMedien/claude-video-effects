# public/

Claude puts your video, the cut-out, the word timestamps and images in this folder. Remotion reads
everything listed in `src/project.ts` from here. Your own files do not end up in the repo (`.gitignore`).

Included: `fonts/` (Montserrat, SIL OFL 1.1) and `lens-map.png` (displacement map for Liquid glass).
